# NOUX · pre-departure UX audit (21 November 2026)

This review covers the publicly versioned application layers and release workflows, not plaintext modules inside the private encrypted vault. No itinerary changes or new bookings are assumed.

## Delivered: Food guide

- 13 Food Wish List entries now have branch-specific addresses, standard published opening hours, source sites, Thanksgiving exceptions, suggested geographic days, and direct directions / current-hours lookup links.
- The new Food guide renders outside the React root. It is reachable from the Wishlist's contextual button, clicking a recognised Food card, or Explore.
- The original four-element private Food Wish rows, priorities and itinerary decisions remain unchanged.
- An unmatched personally added Food entry is clearly labelled as having unverified location and hours, with a search link rather than invented data.
- Holiday warnings are explicit. In particular Russ & Daughters and Lobster Place are closed on 26 Nov; Katz's publishes an 18:00 Thanksgiving closing. Standard hours for Levain and Magnolia differ between official listings.

## Remaining optional improvements

- A more precise **leave-by estimator** using audited door-to-door transit durations, while continuing to distinguish scheduled and predicted MTA data.
- An **in-place React refresh** when Lyna changes an itinerary choice remotely. The current controlled reload prevents stale browser state from overwriting shared selections.
- A deliberately minimal **tax/tip and souvenir budget** if useful during the stay. 
- Local offline cached venue photos and static subway map overlays, subject to mobile storage quotas and licensing, only after the core offline pack passes iPhone testing.

## Release discipline

Do not touch the encrypted private app or add DOM children within React-managed navigation. Initialise new modules after the healthy first paint; maintain mobile layout tests, local data preservation and two-device sync tests. Prioritise dependable offline access and booking readiness ahead of cosmetic features.
